# Augment 1.0.7

Show Desktop is now available in Settings → Windows. Enable it, then:

- Press **Control–Option–D (⌃⌥D)**.
- **Option-click Augment** in the menu bar.
- Click **Show / Restore Desktop** in Augment's quick panel.

Repeat the action to bring your windows back. Uses the native macOS desktop transition, preserves minimized windows, and needs no additional privacy permission. The feature starts off. Settings reports shortcut conflicts; mouse access remains available.

Also includes the Dock click restoration fixes made since 1.0.6.

macOS 13+, Intel and Apple Silicon.

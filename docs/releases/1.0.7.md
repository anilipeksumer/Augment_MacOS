# Augment 1.0.7

Show Desktop is now available in Settings → Windows. Enable it, then:

- Press **Command–D (⌘D)**.
- **Option-click Augment** in the menu bar.
- Click the **desktop icon beside Settings** in Augment's quick panel.

Minimizes open windows to the Dock. Repeat to restore only windows minimized by this action; already minimized windows stay minimized. Requires Accessibility permission. Full-screen windows and windows that do not support minimizing are left unchanged. The feature starts off. Settings reports shortcut conflicts; mouse access remains available.

Also includes the Dock click restoration fixes made since 1.0.6.

macOS 13+, Intel and Apple Silicon.

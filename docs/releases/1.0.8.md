# Augment 1.0.8

**Show Desktop now follows what is on screen.**

- **⌘D** minimizes open windows, even when you open another window after previously showing the desktop.
- Saved windows are restored only when no application windows are visible on the current desktop.
- Newly minimized windows join the saved group. Windows minimized before using Show Desktop stay minimized.
- Option-click on Augment and the quick panel's desktop icon use the same behavior. Clipboard remains **⌘⇧V**.

Requires Accessibility permission. Full-screen windows and windows that reject minimization are left unchanged; visible windows prevent restoring the saved group.

**Updated installer (build 10):** restores the original 1.0.6 drag-to-Applications layout. The Settings window is now titled “Augment” in both languages, and the README screenshot has been refreshed.

macOS 13+, Intel and Apple Silicon.

# Augment 1.0.9

Choose how Enter works in Finder, in Settings → Finder:

1. **macOS (default):** Enter renames.
2. **Enter renames, Shift-Enter opens** the selected files or folders.
3. **Enter opens, Shift-Enter renames** the selected files or folders.

Supports Return and numeric keypad Enter. Renaming, search fields and dialogs keep normal text editing behavior. Other apps are unaffected. Custom modes require Accessibility permission.

Additional opt-in Finder tools:

- Backspace and double-clicking empty folder space go to the parent folder.
- Middle-click a folder to open it in a new tab.
- F2 renames the selection in any Enter mode (Fn-F2 on some keyboards).
- Paste a clipboard image with Command-V to create a PNG without overwriting existing files.

Clipboard history now includes image thumbnails and new screenshots saved by macOS. Screenshots are copied into Augment's own history storage, so removing the original does not remove the history entry. Images can be pinned, copied, pasted and removed like text. The screenshot option is in Settings → Notch → Clipboard and works when clipboard history or its panel is enabled. Command-Shift-V remains the clipboard panel shortcut.

Middle-click and image paste require Finder Automation in addition to Accessibility. Other Finder shortcuts require Accessibility only.

Screenshot arrivals now show a brief camera/checkmark animation beside the closed notch. They do not expand the panel or switch the tab you are using.

The DMG keeps the original Augment installer design.
